# Vortex Overlay

Vortex Overlay is a Windows desktop overlay application designed to provide a lightweight and convenient overlay experience while using other applications.

> **Status:** Development / Early Release  
> **Current Version:** v1.0.0  
> **Platform:** Windows

---

## ✨ Features

- Lightweight Windows overlay
- Simple and clean interface
- Fast startup
- Designed to run alongside other applications
- Easy installation
- Automatic application launch after installation
- Regular updates through GitHub Releases
